## 📌 專案簡介

**ReadMap** 是一個以「互動式世界地圖 × 國家深度內容」為核心的探索型網站。我們將複雜的全球地理數據、空間地圖與結構化內容完美整合，提供**繁體中文／英文（Bilingual）**雙語閱讀體驗，讓使用者跳脫傳統「純查資料」的限制，直觀探索全球 200 多個國家的地理、文化、政治與國際關係。

---

## 🗺️ 核心功能與網頁內容

### 1. ⛰️ 互動式世界地圖與多功能圖層
支援多圖層疊加功能，視覺化呈現全球地理與地質樣貌，完美契合國中、高中地理教材，是學生與老師的最佳課堂夥伴：
* **地形地勢圖 (Topology)**：細緻呈現全球山脈、高原盆地與陸塊的地勢起伏。
* **等高線圖 (Contours)**：精準掌握全球各地的海拔高度變化。
* **人口分布點子圖 (Worldpop Dots)**：視覺化呈現全球人口稠密區、主要大都市與聚落分布。
* **洋流圖 (Currents)**：動態模擬全球各大洋流走向與海洋動態。
* **板塊構造與行政區劃 (Tectonic Plates & Admin)**：直觀看清全球地震帶、板塊邊界與各國最新的行政疆界。

### 2. 📊 200+ 國家深度檔案與統計資訊
每個國家皆建立詳盡的結構化國家檔案，涵蓋最新年度的名目 GDP 數據與客觀資料：
* **基本識別**：官方國旗、國徽、ISO 代碼、國際電話區號、駕駛方向與一週起始日。
* **地理與氣候**：跨洲地理位置分析、重要海峽與戰略通道控制、各地區氣候類型與變化幅度。
* **文化與社會**：深入介紹世界級歷史文明遺產、指標性考古古城遺跡、多元族群分布、宗教文化與傳統飲食藝術。
* **當前議題與國際關係**：追蹤各國近年面臨的通膨與貨幣波動、難民與移民議題，以及在北約（NATO）或各大區域地緣政治中所扮演的關鍵角色。
* **🇹🇼 台灣專屬關係連結**：特別整理全球各國與台灣的非官方經貿往來、觀光交流、民間友好互動與物流合作基礎，精準引流高質量的真人搜尋。
